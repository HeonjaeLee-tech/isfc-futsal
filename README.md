# ISFC 20주년 OBYB 풋살대회 사이트

2026년 10월 31일(토) 한양대 ERICA 풋살장. 주차 안내, 실시간 경기 현황, 득점왕, 팀 정보, 기념품, 안주, 뒤풀이 공지를 폰으로 보는 사이트예요.
화면은 GitHub Pages가 띄우고, 내용은 구글 시트에서 20초마다 읽어와요.

## 1. 구글 시트 연결 (한 번만)

1. `ISFC_풋살대회_운영시트.xlsx`를 구글 드라이브에 올리고 열기 → **파일 → Google 스프레드시트로 저장**
2. 오른쪽 위 **공유** → 일반 액세스를 **링크가 있는 모든 사용자 · 뷰어**로
3. 주소창 링크에서 `/d/`와 `/edit` 사이 글자를 복사
4. 이 저장소의 `assets/js/config.js`에서 `SHEET_ID: ""` 따옴표 안에 붙여넣기 (GitHub 웹에서 연필 아이콘으로 수정 가능)

`SHEET_ID`가 비어 있으면 화면 확인용 샘플 데이터로 보여요.

## 2. GitHub Pages 켜기

1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 으로 접속

## 3. 당일 운영 (시트만 고치면 됨)

| 할 일 | 시트 | 방법 |
|---|---|---|
| 경기 시작 | 경기 | 상태를 `진행중` |
| 골 | 경기 → 득점 | 홈골/원정골 숫자 수정, 득점 시트 맨 아래에 경기번호 + 선수 |
| 경기 끝 | 경기 | 상태를 `종료` (순위표, 대진표 자동 갱신) |
| 토너먼트 무승부 | 경기 | 승부차기 칸에 `4-3` (홈-원정) |
| 공지 | 공지 | 맨 아래 줄 추가 → 사이트 맨 위 배너. 긴급은 버건디 배너 |
| 팀 공개 | 설정 | 팀공개를 `O` |

시트 1행 제목과 탭 이름은 바꾸지 마세요. 사이트가 그 이름으로 읽어요.

## 파일 구성

- `index.html` 페이지 뼈대 (주차 안내는 여기 고정 내용)
- `assets/css/style.css` 디자인
- `assets/js/app.js` 시트 읽기, 순위/대진/득점왕 계산, 화면 그리기
- `assets/js/config.js` 시트 ID와 새로고침 간격
- `assets/js/demo.js` 샘플 데이터
- `assets/img/` 키비주얼, 엠블럼, 지도, 기념품 사진
- `tools/` 시트 템플릿, 샘플 데이터, 아이콘 생성 스크립트 (사이트 동작엔 필요 없음)
