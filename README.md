# ISFC 20주년 OBYB 풋살대회 사이트

2026년 10월 31일(토) 한양대 ERICA 풋살장. 주차 안내, 실시간 경기 현황, 득점왕, 팀 정보, 기념품, 안주, 뒤풀이 공지를 폰으로 보는 사이트예요.
화면은 GitHub Pages가 띄우고, 내용은 구글 시트에서 20초마다 읽어와요.

## 구글 시트

운영 시트는 구글 드라이브에 있고 `config.js`의 `SHEET_ID`로 연결돼 있어요. 시트 공유는 "링크가 있는 모든 사용자 · 뷰어"를 유지해야 해요.
`SHEET_ID`를 비우면 화면 확인용 샘플 데이터로 보여요.

## 당일 운영 (시트만 고치면 됨)

| 할 일 | 시트 | 방법 |
|---|---|---|
| 경기 시작 | 경기 | 상태를 `진행중`. 늦게 시작하면 `시작` 칸도 실제 시각으로 (타이머 기준) |
| 골 | 경기 → 득점 | 홈골/원정골 숫자 수정, 득점 시트 맨 아래에 경기번호 + 선수 |
| 경기 끝 | 경기 | 상태를 `종료` (순위표, 대진표 자동 갱신) |
| 토너먼트 무승부 | 경기 | 승부차기 칸에 `4-3` (홈-원정) |
| 공지 | 공지 | 맨 아래 줄 추가 → 사이트 맨 위 배너. 긴급은 버건디 배너 |
| 팀 공개 | 설정 | 팀공개를 `O` |

시트 1행 제목과 탭 이름은 바꾸지 마세요. 사이트가 그 이름으로 읽어요.

## 조 추첨

조 추첨은 현장에서 직접 뽑아요. `조 추첨` 탭은 이름 공이 굴러가는 추첨기 그림과 참가자 명단을 보여 주고, 12:40~13:00에는 '조 추첨 진행 중'으로 바뀌어요. 13시 이후 도착한 사람은 남은 자리에 임의로 배정한다고 안내해요.

- 참가자 명단: `draw.js` (이름만). 설정 시트 `추첨 제외` / `추첨 추가` 칸(쉼표로 구분)으로 화면 명단 조정
- 추첨이 끝나면: 선수 시트에 이름과 팀코드(A1~A5 = 1~5조, B1~B5 = 6~10조)를 적고 설정의 `팀공개`를 `O`로 → 조 추첨 탭, 팀 화면, 경기 일정에 팀이 떠요

## 팀 꾸미기

사이트의 `팀 꾸미기` 탭에서 누구나 팀 이름과 엠블럼 사진을 바꿀 수 있어요. 바꾸면 경기 현황, 순위표, 대진표, 팀 화면에 바로 반영돼요.

- 저장되는 곳: 구글 드라이브의 `ISFC 팀 꾸미기 저장소 (사이트 자동 저장)` 시트 (운영 시트와 별개, 공개 안 됨)
- 연결: 그 시트에 붙은 Apps Script(`deco_apps_script.gs`와 같은 코드)를 웹앱으로 배포한 주소가 `config.js`의 `DECO_URL`
- 장난으로 바뀌면: 저장소 시트의 `팀꾸미기` 탭에서 그 팀 칸을 비우거나 `기록` 탭에서 예전 값을 복사해 넣기
- 마감: 저장소 시트의 `설정` 탭에서 `잠금`을 `O`로 바꾸면 더 이상 못 바꿔요
- 우선순위: 팀 꾸미기 이름 > 운영 시트 `팀` 탭의 팀명 > `A1팀` 같은 기본 이름

## 파일 구성 (모두 저장소 최상단)

- `index.html` 페이지 뼈대 (주차 안내는 여기 고정 내용)
- `style.css` 디자인
- `app.js` 시트 읽기, 순위/대진/득점왕 계산, 시계와 경기 타이머, 화면 그리기
- `config.js` 시트 ID, 팀 꾸미기 주소(DECO_URL), 새로고침 간격
- `deco_apps_script.gs` 팀 꾸미기 저장소 Apps Script 코드 (보관용 사본, 실제로는 구글 쪽에서 실행)
- `demo.js` 샘플 데이터, `icons.js` 아이콘
- 이미지: `keyvisual.jpg`, `emblem.png`, `hanyangi.png`, `map-parking.jpg`(주차 안내 지도), `tumbler.jpg`, `keyring.jpg`
- `build_*.py` 시트 템플릿, 샘플 데이터, 아이콘 생성 스크립트 (사이트 동작엔 필요 없음)
